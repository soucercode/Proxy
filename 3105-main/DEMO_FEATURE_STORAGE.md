# Demo feature files

Bundled .3105 files are included as app resources for UI/demo testing.
When a feature is enabled, the app copies its resource into the app's own sandbox:
Library/Caches/ProxySHOPDHP/features/

It does not write to another app's data container or modify Free Fire/Free Fire Max data.
Each supported demo feature shows a 3-second circular loading indicator in the same switch position.
Maintenance features automatically switch off and show a maintenance alert.
